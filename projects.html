QLeaf ↗

Low-latency tree inference

6.9 µsBest GPU median, 5,000 trees

Reaches single-digit microsecond latency for hundreds to thousands of shallow trees.

QLeaf aggressively optimizes data transfer and cross-block coordination, and uses a lock-free host–device handoff to bring end-to-end latency close to the limits of host–device communication.

GardenPipe ↗

Processing arbitrarily large data with bounded batch memory

A training and testing framework for sequence-like data many times larger than RAM. It streams one date at a time in fixed-size batches, so memory is a bound you set rather than a side effect.

Built on Polars for a single workstation, not a cluster. Stateful features carry across batch boundaries, so streaming gives the same numbers as a full pass, and prefetch runs against a byte budget. Growing the dataset adds time, not memory.

  • Python
  • Polars
  • Streaming

OptIndex ↗

Safe intrusive object store

Stable addresses and compile-time index definitions. Centralized storage and object lifetime management keep optional or partitioned views consistent without duplicating objects.

Built for bounded working sets and repeated queries, with explicit indexing control and an optional fixed-size pool. The design addresses consistency across indices without duplicating the stored objects.

  • C++
  • Boost.Intrusive
  • Memory management

RL Tools ↗

Composable reinforcement learning

A lightweight reinforcement learning framework that separates agents from their value models. SARSA and Q-learning agents work with tabular storage or Torch-based function approximators.

Template-based interfaces keep the interaction loop small: observe a state, select an action, and collect a reward. Core components are header-only; neural models use LibTorch.

  • C++
  • Templates
  • LibTorch

QuDrip ↗

Exact quantum many-body simulation

A toolbox for constructing constrained Hilbert spaces, quantum operators, and Hamiltonians. Sparse-matrix and Krylov methods support ground-state calculations, real-time evolution, and Lindblad dynamics.

Designed for flexible small-to-medium quantum systems, including fermionic and bosonic degrees of freedom. Used in research on quantum-light control and photodoped superconductivity.

  • C++
  • Eigen
  • Krylov methods

NESSi 2.0 ↗

Nonequilibrium systems simulation

A shared research library for nonequilibrium Green’s functions and interacting quantum systems. Version 2.0 adds memory-truncated time propagation and steady-state calculations.

I contributed to the development of NESSi 2.0 through my research on nonequilibrium many-body methods. The package supports accurate numerical integration and distributed-memory calculations for quantum dynamics.

  • C++
  • Green’s functions
  • DMFT

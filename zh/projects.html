QLeaf ↗

低延迟树模型推理

6.9 µsGPU 最佳中位延迟（5,000 棵树）

可对数百至数千棵浅层树实现个位数微秒延迟。

QLeaf 深入优化数据传输与线程块间的协调，并采用无锁的主机与设备之间的交接机制，使端到端延迟接近主机与设备通信的极限。

  • C++
  • CUDA
  • CPU / GPU

GardenPipe ↗

以受限的批次内存处理任意规模的数据

面向序列数据的训练与测试框架，数据量可达内存容量的许多倍。它按日期逐日读取，并以固定大小的批次流式处理，让内存成为由你设定的上限，而不是运行的副作用。

基于 Polars，专为单台工作站而非集群设计。有状态特征可跨批次延续，流式处理与完整运行的结果一致；后台预取受字节预算限制。数据量增长只增加时间，不增加内存。

  • Python
  • Polars
  • 流式处理

OptIndex ↗

安全的侵入式对象存储

具有稳定地址和编译期索引定义。集中管理存储与对象生命周期，使可选视图和分区视图保持一致，无需复制对象。

面向有界工作集和重复查询，提供显式索引控制与可选的固定大小内存池。设计重点是在不复制存储对象的前提下，保证不同索引间的一致性。

  • C++
  • Boost.Intrusive
  • 内存管理

RL Tools ↗

可组合的强化学习

一个轻量级强化学习框架，将智能体与其价值模型分离。SARSA 和 Q-learning 智能体可使用表格存储，也可使用基于 Torch 的函数近似器。

基于模板的接口使交互循环保持简洁：观察状态、选择动作、获得奖励。核心组件仅依赖头文件；神经网络模型使用 LibTorch。

  • C++
  • 模板
  • LibTorch

QuDrip ↗

精确量子多体模拟

用于构造受约束希尔伯特空间、量子算符和哈密顿量的工具箱。通过稀疏矩阵与 Krylov 方法，支持基态计算、实时演化和 Lindblad 动力学。

面向中小规模量子系统的灵活计算，支持费米子与玻色子自由度。已用于量子光调控和光掺杂超导的研究。

  • C++
  • Eigen
  • Krylov 方法
